# 2026-09-28

## Goal

- VR Teleoperation 연결 환경 단순화 및 안정성 개선 방안 검토

## Discussion

현재 사용 중인 연결 구조:

```text
Quest 2
→ ALVR
→ SteamVR
→ OpenVR
→ MuJoCo
```

현재 구조는 연결 오류와 디버깅 시간이 많이 발생함.

정동현과 함께 다음 구조를 대안으로 검토:

```text
Quest 2
→ WiVRn
→ OpenXR
→ MuJoCo
```

## Decision

- 기존 `SteamVR + ALVR` 성공 코드는 baseline으로 보존
- 기존 코드를 바로 교체하지 않고 `WiVRn + OpenXR` 환경을 별도로 테스트
- OpenXR 기반 환경이 더 안정적인지 확인 후 최종 연결 방식 결정

## Test Plan

1. WiVRn ↔ Quest 2 연결
2. OpenXR에서 HMD pose tracking 확인
3. HMD pose → MuJoCo camera 연동
4. 기존 `ALVR + SteamVR` 환경과 비교

### Comparison

- 연결 안정성
- 재연결 편의성
- Latency
- 화면 왜곡
- 디버깅 난이도
